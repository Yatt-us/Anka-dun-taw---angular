# Fonctionnalités de l’application

Le web couvre trois acteurs : `admin`, `dieteticien` et `nutritionniste`, avec une authentification partagée. L’application mobile grand public est développée dans Flutter.

Les fonctionnalités possèdent déjà leurs tableaux de bord et certains écrans dédiés. Une partie des rubriques de gestion reste dans le composant d’espace mutualisé sous `shared/`; ce composant est un point de transition, pas l’organisation cible pour la logique métier. Voir [`../STRUCTURE.md`](../STRUCTURE.md) pour l’inventaire actuel et la cible de migration.
