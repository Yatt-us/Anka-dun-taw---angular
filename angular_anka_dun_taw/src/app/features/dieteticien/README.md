# Feature Diététicien(ne)

Écrans prévus d’après Figma : tableau-de-bord, patients, menus, demandes-adaptation, recettes, portions-couts, suivi-utilisateurs, profil.

Les pages Angular standalone seront dans `pages/`, leurs éléments propres dans `components/`, les appels API dans `data-access/`, les types dans `models/` et les routes dans `routes/`. Les éléments partagés entre acteurs vont dans `src/app/shared/`.
